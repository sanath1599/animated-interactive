Built for reliable delivery

Large files are sent in small pieces, each checked on arrival. The sizes below are the project's documented settings, not measured results.

Size of each piece, by device and file size

Phones & tabletsComputers

Safeguards described in the project

✅ Integrity check

Every piece and the finished file are verified with a SHA-256 fingerprint.

🔄 Automatic retry

A piece that fails is retried up to 3 times.

🔍 Gap detection

Missing pieces are noticed and re-requested.

📱 Mobile care

Large files on phones (over 50 MB) are held in on-device storage to avoid memory problems.

📶 Family mode

Warns when a device is on mobile data instead of the shared WiFi.

What c0py.me already offers

Simple to use

Pick a sharing world, choose files, choose a person. No account is needed; names are generated automatically.

In the recipient's control

Recipients see the file details and approve before anything is received.

Designed for dependability

Pieces are verified, retried when they fail, and sized for the device in use.
